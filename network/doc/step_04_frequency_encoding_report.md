# Step 04 频率编码输入实验报告

## 1. 实验目的
- 解决坐标直接输入对高频细节拟合不足的问题。
- 验证 Fourier/Frequency Encoding 对纹理细节恢复的增益。

## 2. 实验原理
- **输入编码策略**：
  - 将原始 `uv` 扩展为多频正余弦特征；
  - 每个 octave 生成 `sin/cos(u*scale), sin/cos(v*scale)` 四个特征；
  - `NumOctaves=4` 时总输入维度 `2*4*2=16`。
- **网络结构**：编码后输入网络 `16->32->32->3`。
- **激活策略**：继承 Step 03（隐藏层 LeakyReLU，输出层 exp）。
- **理论依据**：将低维坐标映射到高维周期基后，MLP 更容易拟合高频变化。

## 3. 实验手段
- 在 Slang `eval` 中新增频率编码循环，构造 `encoded_inputs`。
- Python 侧第一层输入维度同步改为 16。
- 训练、损失、优化器保持与前序一致，突出编码贡献。

## 4. 实验条件
- 频率 octave 数：4。
- 第一层输入维度：16。
- 学习率：`0.001`。
- 批次：`64x64`。
- 每帧训练步数：20。

## 5. 实验步骤
1. 加载 `step_04_frequency_encoding.slang`。
2. 构建 `16->32->32->3` 网络参数。
3. 在 `eval` 阶段对输入 `uv` 执行多尺度正余弦编码。
4. 进入训练循环，观察重建纹理与损失变化。
5. 与 Step 03 结果进行视觉与误差对比。

## 6. 实验结果
- 高频编码显著提升了网络对细纹理与边缘的恢复能力。
- 在相同模型宽度下，编码输入通常可达到更高拟合质量和更快的细节收敛。
- 代价是输入维度增加，首层计算量上升，但总体收益明显。
- 结论：Frequency Encoding 是该任务中提升细节表现的关键技术之一。
