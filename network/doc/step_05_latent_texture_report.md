# Step 05 潜变量纹理（Latent Texture）实验报告

## 1. 实验目的
- 探索“可学习输入表示”替代手工频率编码的方案。
- 通过联合优化潜变量纹理与 MLP 参数，提升纹理拟合灵活性。

## 2. 实验原理
- **潜变量纹理结构**：维护一个可训练三维张量 `H x W x C`，本例为 `32x32x4`。
- **采样机制**：对任意 `uv` 在潜变量网格上做双线性插值，得到 4 维 latent code。
- **联合训练**：
  - latent 纹理元素通过自定义 backward 写入 `texture_grads`；
  - MLP 参数和 latent 共同使用 Adam 更新。
- **网络结构**：`latent(4)->32->32->3`，隐藏层 LeakyReLU，输出层 exp。
- **关键思想**：让模型自己学习最有利于重建任务的输入特征分布。

## 3. 实验手段
- 新增 `LatentTexture` 实例类型（Python + Slang 同步定义）。
- 在 `Network.eval` 中先 `sample(uv)` 取 latent，再送入 MLP。
- 将 latent tensor 及其 Adam 状态纳入每步 `optimize`。

## 4. 实验条件
- 潜变量纹理尺寸：`32x32`。
- 潜变量通道数：4。
- 潜变量初始化：`[0,1]` 均匀随机。
- 学习率：`0.001`。
- 批次：`64x64`。
- 每帧训练步数：20。

## 5. 实验步骤
1. 加载 `step_05_latent_texture.slang`。
2. 初始化 `LatentTexture(32,32,4)` 与三层 MLP。
3. 每次前向：`uv -> latent 双线性采样 -> MLP -> RGB`。
4. 每轮反向同时累积网络参数梯度与 latent 梯度。
5. 使用 Adam 同步更新 latent 与网络权重，观察重建改进。

## 6. 实验结果
- 潜变量纹理提供了更具适应性的输入表示，通常可进一步提升复杂局部模式重建质量。
- 相比固定频率编码，latent 表示可“数据驱动”地分配表达容量。
- 训练参数规模增大，优化空间更复杂，可能需要更长训练时间与更细致超参数调优。
- 结论：Step 05 展示了“显式可学习特征场 + 小型 MLP”在神经纹理任务中的高潜力。
