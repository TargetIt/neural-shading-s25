# Step 03 激活函数改进实验报告

## 1. 实验目的
- 通过替换激活函数改善梯度传播，提升训练稳定性与拟合质量。
- 研究 `LeakyReLU + exp` 组合相较 `ReLU` 的实际效果。

## 2. 实验原理
- **隐藏层激活**：使用 `LeakyReLU(x)=x(x>0), slope*x(x<=0)`，保留负半轴小梯度，缓解死神经元。
- **输出层激活**：使用 `exp`，确保 RGB 输出为正值，同时提升动态范围表达。
- **网络结构**：仍为 `2->32->32->3`，与 Step 02 保持可比性。
- **优化流程**：随机采样 + 自动微分 + Adam 不变，便于单变量对比（激活函数）。

## 3. 实验手段
- 在 Slang 侧将两层隐藏激活由 ReLU 改为 LeakyReLU。
- 输出层激活改为 `exp`。
- Python 侧训练流程保持一致，确保改动集中在网络表达层。

## 4. 实验条件
- 学习率：`0.001`。
- 批次：`64x64`。
- 每帧迭代：20。
- 隐藏层宽度：32。
- 数据与可视化方式与前序实验一致。

## 5. 实验步骤
1. 加载 `step_03_better_activations.slang`。
2. 初始化三层参数并进入训练循环。
3. 每帧渲染预测图与损失图，同时执行 20 次反向传播。
4. 对比 Step 02 的损失下降速度与图像细节恢复情况。

## 6. 实验结果
- LeakyReLU 改善了负区间梯度中断问题，训练更平滑，早期收敛更稳定。
- 输出层 `exp` 使颜色输出始终为正，能更自然拟合纹理亮度分布。
- 在相同训练设置下，通常可获得更低误差和更细腻重建。
- 结论：激活函数选择对可训练性影响显著，Step 03 为高频编码/潜变量实验提供更稳健基座。
