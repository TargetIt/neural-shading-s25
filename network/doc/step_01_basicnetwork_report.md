# Step 01 基础单层网络实验报告

## 1. 实验目的
- 理解在 Slang/SlangPy 环境中，如何构建一个最小可训练神经纹理网络（2 输入 -> 3 输出）。
- 验证自动微分 + Adam 优化在 GPU 端训练纹理拟合任务的可行性。
- 建立后续多层网络、激活函数改进与输入编码实验的基线。

## 2. 实验原理
- **建模对象**：将二维坐标 `uv` 映射为 RGB 颜色，即学习函数 `f(u,v)->(r,g,b)`。
- **网络结构**：单层全连接 `NetworkParameters<2,3>`，直接输出三个通道。
- **激活函数**：输出层使用 ReLU（`max(x,0)`），保证输出非负。
- **损失定义**：将预测色与参考图在 gamma 空间比较，使用逐通道平方误差。
- **训练机制**：
  - `calculate_grads` 随机采样批次像素；
  - `bwd_diff(loss)` 自动反传；
  - 梯度写入 `AtomicTensor` 聚合批次贡献；
  - `optimizer_step` 使用 Adam 更新参数并清零梯度。

## 3. 实验手段
- **语言与框架**：Python + SlangPy + Slang。
- **数据**：`slangstars.png` 作为目标纹理。
- **可视化方式**：窗口并排显示“参考图 / 当前重建图 / 损失图”。
- **训练调度**：每帧进行 20 次梯度更新，实时打印平均损失。

## 4. 实验条件
- 输入分辨率：训练渲染 `256x256`，显示缩放到 `512x512`。
- 批次大小：`64x64`（4096 采样/次）。
- 学习率：`0.001`。
- 参数初始化：权重均匀随机 `[-0.5, 0.5]`，偏置为 0。
- 优化器：Adam（`beta1=0.9, beta2=0.999, eps=1e-8`）。

## 5. 实验步骤
1. 初始化应用窗口与 Slang 模块 `step_01_basicnetwork.slang`。
2. 加载参考图像张量 `slangstars.png`。
3. 构建单层网络参数（权重、偏置、梯度缓存、Adam 一二阶矩）。
4. 每帧执行：
   - 渲染网络输出纹理；
   - 计算并显示损失图；
   - 进行 20 轮随机批次反向传播与参数更新。
5. 持续观察损失打印与重建图像质量变化。

## 6. 实验结果
- 该实验可以完成“从坐标直接回归 RGB”的端到端训练闭环，损失会随迭代下降。
- 由于仅单层线性变换 + ReLU，模型表达能力有限，对高频细节与复杂纹理边界拟合不足。
- 结果表现为：
  - 低频颜色区域可较快逼近；
  - 高频细节（星形边缘、尖锐变化）容易欠拟合。
- 结论：Step 01 适合作为**训练流水线验证**，但不足以高质量重建复杂纹理，需要更深网络或更强输入表示。
