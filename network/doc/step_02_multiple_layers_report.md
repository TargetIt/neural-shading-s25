# Step 02 多层网络实验报告

## 1. 实验目的
- 在 Step 01 基线之上，引入多层 MLP，提升纹理函数拟合能力。
- 对比单层与三层结构在细节恢复和收敛稳定性上的差异。

## 2. 实验原理
- **网络结构升级**：`2->32->32->3` 三层全连接。
- **非线性建模**：每层后使用 ReLU，提高网络对非线性映射的表达能力。
- **其余训练链路不变**：仍采用随机批次采样、自动微分、Adam 更新、gamma 空间 MSE。
- **核心思想**：增加隐藏层和通道数以扩大函数空间，从而更好拟合目标纹理。

## 3. 实验手段
- 复用 Step 01 的 Python 训练框架与可视化布局。
- 在 Python 侧将网络参数扩展为三个 `NetworkParameters` 实例。
- 在 Slang 侧按顺序执行三层 `forward + activation`。

## 4. 实验条件
- 学习率：`0.001`。
- 批次大小：`64x64`。
- 每帧优化步数：20。
- 初始化策略与优化器参数与 Step 01 保持一致。

## 5. 实验步骤
1. 加载 `step_02_multiple_layers.slang` 模块。
2. 构建三层网络参数：
   - `layer0: 2->32`
   - `layer1: 32->32`
   - `layer2: 32->3`
3. 每帧渲染当前结果并计算 loss 可视化。
4. 迭代执行 20 次 mini-batch 反传与 Adam 更新。
5. 观察损失曲线与视觉结果变化。

## 6. 实验结果
- 相比单层网络，三层结构在细节表示上明显增强，重建图像更接近参考纹理。
- 收敛阶段通常表现为更低的稳态损失，纹理边缘与局部变化恢复更好。
- 但 ReLU 在负半轴梯度为零，仍可能出现局部“死神经元”现象，影响进一步优化。
- 结论：增加网络深度显著提升拟合能力，是后续激活函数改进的前提。
