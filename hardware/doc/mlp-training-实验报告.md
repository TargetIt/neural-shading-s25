# mlp-training 示例实验报告

## 实验目的
1. 理解在 **不使用 cooperative vector 专用硬件指令** 的条件下，如何基于 Slang 自动微分完成 MLP 训练。
2. 掌握该示例中“前向推理 + 反向梯度 + Adam 参数更新”的完整 GPU 训练闭环。
3. 建立后续与 `mlp-training-coopvec` 的性能/实现对照基线。

## 实验原理
1. **网络结构**：两层全连接网络，结构为 `4 -> 16 -> 4`。
2. **输入编码**：将二维输入 `(x, y)` 扩展为四维特征 `[x, y, x^2, y^2]`。
3. **监督目标**：网络拟合一个 4 维多项式表达式（`groundtruth`）。
4. **损失函数**：网络输出与目标输出做差后取平方和（L2 loss）。
5. **梯度计算方式**：通过 Slang 自动微分（`bwd_diff(loss)`）在 `learnGradient` 计算核中求梯度。
6. **参数更新**：`adjustParameters` 核使用 Adam 逐元素更新参数，并在梯度为 NaN 时做保护清零。

## 实验手段
1. **代码静态分析**：阅读 `mlp-training.cpp` 与 `.slang` 核心文件，提取训练流程、数据流、缓冲区布局。
2. **流程拆解**：将训练循环分解为 loss 清零、梯度计算、Adam 更新、周期性 loss 输出四个阶段。
3. **结果判定方式**：以程序中每 10 次迭代打印的 `Loss after N iterations` 为训练收敛观测指标。

## 实验条件
1. 平台：Windows / Linux / macOS（README 指示该示例跨平台支持）。
2. 图形后端：Windows/Linux 使用 Vulkan，macOS 使用 Metal。
3. 依赖：CMake、C++17 编译器、Slang/slang-rhi 及其子模块。
4. 训练配置（由示例代码固定）：
   - 迭代次数：1000
   - 输入样本缓冲：32 个浮点数（按 `float2` 解释即 16 组 `(x,y)`）
   - 损失输出频率：每 10 次迭代打印一次

## 实验步骤
### Step 1：初始化运行环境与设备
1. 解析命令行参数并创建 RHI 设备。
2. 按平台选择目标配置：
   - macOS：Metal (`metal_2_4`)
   - 其他平台：Vulkan (`spirv_1_6`)
3. 加载 `learnGradient` 和 `adjustParameters` 两个计算核。

### Step 2：构建网络参数存储
1. 为每层分配权重/偏置及其梯度区，按 64 字节对齐。
2. 参数缓冲区采用“两段式布局”：
   - 段 1：权重和偏置
   - 段 2：对应梯度
3. 参数初值随机化到 `[-1, 1]`，梯度区初始化为 0。
4. 创建 Adam 状态缓冲区并清零。

### Step 3：准备训练输入与常量缓冲
1. 构建网络常量缓冲：写入每层权重/梯度/偏置地址。
2. 构建输入缓冲：随机生成训练输入。
3. 创建 loss 缓冲，作为每轮训练 loss 的归约输出。

### Step 4：执行训练循环（1000 次）
1. 每轮开始先清零 loss 缓冲。
2. 调度 `learnGradient`：执行前向+反向传播，累积/归约 loss。
3. 调度 `adjustParameters`：基于 Adam 更新参数。
4. 每 10 轮读取并打印一次当前 loss。

### Step 5：观察与记录输出
1. 关注 loss 是否随迭代整体下降。
2. 检查是否存在梯度 NaN（由内核保护逻辑兜底）。
3. 记录 loss 打印序列用于与 coopvec 版本对照。

## 实验结果
1. **结果形式**：程序会输出 `Loss after 10/20/.../1000 iterations: <value>`。
2. **收敛判断标准**：若训练正常，loss 应呈整体下降趋势（允许局部波动）。
3. **实现层面结论**：该示例完整演示了在通用向量/矩阵实现下，使用 Slang 自动微分和 Adam 完成 GPU 端 MLP 训练。
4. **对照意义**：该实现可作为 cooperative vector 加速版本的功能正确性与性能比较基线。
