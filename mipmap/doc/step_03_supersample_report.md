# Step 03：先全分辨率渲染后降采样（Supersample）实验报告

## 1. 实验目的
- 构建与 Step 02 对应的另一条路径：先高分辨率渲染，再对渲染结果降采样。
- 对比两条路径的差异：
  - 路径 A：降采样输入后渲染（Step 02）；
  - 路径 B：高分辨率渲染后降采样（Step 03）。
- 为误差度量与训练目标提供“更接近真实积分”的参考结果。

## 2. 实验原理
- 使用 Step 02 同一套 `render` 与 `downsample` kernel。
- 先基于原始分辨率材质得到全分辨率输出。
- 再对输出图像连续降采样两次，得到 1/4 分辨率结果。
- 该过程相当于将更多高频信息先纳入着色计算，再进行重建。

## 3. 实验手段
- Python 端仍使用 `downsample(source, steps)`。
- `module` 复用 `step_02_mipmap.slang`，说明该实验重点是“流程差异”而非“模型差异”。
- 结果以放大方式显示，便于和 Step 02 主观比较。

## 4. 实验条件
- 窗口分辨率：`1024x1024`。
- 渲染初始分辨率：与原贴图一致（全分辨率）。
- 输出降采样级数：2 级（1/4 尺寸）。
- 光照方向、观察方向与前两步一致。

## 5. 实验步骤
1. 加载贴图并初始化渲染模块。
2. 先在全分辨率上执行 `render` 得到 `output`。
3. 对 `output` 执行 `downsample(output, 2)`。
4. 将低分辨率结果放大到窗口显示。
5. 与 Step 02 结果进行并行主观对照（推荐）。

## 6. 实验结果
- 实现了“**先渲染再降采样**”的参考路径。
- 相比 Step 02，通常能更好保留 BRDF 非线性导致的能量与高光结构。
- Step 03 的结果在 Step 04 中被用作 reference（近似真值）进行像素级损失计算。
