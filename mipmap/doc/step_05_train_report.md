# Step 05：可微训练低分辨率材质实验报告

## 1. 实验目的
- 利用可微渲染与反向传播，学习一组低分辨率材质贴图，使其渲染结果逼近 reference。
- 将 Step 04 的损失定义扩展为可迭代优化流程。
- 验证 Adam 在材质参数（albedo/normal/roughness）空间中的收敛能力。

## 2. 实验原理
- `step_05_train.slang` 为材质访问函数添加 `[Differentiable]` 与反向函数（`BackwardDerivativeOf`），把梯度写入梯度张量。
- `calculate_grads(...)` 中随机采样光照和视角，在高分辨率材质上做 4x4 子像素平均作为监督，再对 `loss` 执行 `bwd_diff`。
- 优化器使用 Adam：维护一阶矩 `m`、二阶矩 `v`，并进行 bias correction。
- 对 normal 贴图更新后执行归一化；对 albedo/roughness 执行 `saturate` 约束到 `[0,1]`。

## 3. 实验手段
- 初始化待训练贴图：
  - albedo = 常数 `0.5`；
  - normal = `(0,0,1)`；
  - roughness = `0.5`。
- 每帧执行 50 次优化迭代，学习率从 `0.002` 线性衰减到 `0.0002`（3000 步内）。
- 同时显示：reference、训练结果、当前 loss 图，并打印平均损失值。

## 4. 实验条件
- 窗口：`3092x1024` 三栏可视化。
- 训练分辨率：低分辨率材质（原图经 2 级降采样）。
- 采样策略：半球随机方向（LCG）生成光照与观察方向。
- 每帧优化次数：50；累计步数由 `optimize_counter` 记录。

## 5. 实验步骤
1. 构造低分辨率真值贴图（直接降采样得到）与可训练贴图（常数初始化）。
2. 前向渲染 reference（高分辨率后降采样）与当前训练结果。
3. 分别计算原始低分辨率贴图的 loss（对照）与训练贴图的 loss（当前目标）。
4. 循环调用 `calculate_grads` + `optimizer_step` 更新三类贴图参数。
5. 读取 loss 到 NumPy，输出 `Loss` 与 `Original Loss` 监控优化进展。

## 6. 实验结果
- 构建了完整的“可微渲染监督训练”闭环：前向渲染、反向求导、参数更新、可视化监控。
- 若优化有效，`Loss` 会逐步接近并有机会低于固定降采样材质对应的 `Original Loss`。
- 该步骤说明：通过学习得到的低分辨率材质，能够在相同渲染预算下更好逼近高分辨率参考外观。
