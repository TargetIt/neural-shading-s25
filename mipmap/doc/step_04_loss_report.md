# Step 04：损失可视化实验报告

## 1. 实验目的
- 建立两类低分辨率结果间的误差度量：
  1) 全分辨率渲染后降采样（reference）；
  2) 低分辨率材质直接渲染（prediction）。
- 将误差以图像方式可视化，定位差异区域。
- 为 Step 05 的参数优化提供监督信号定义。

## 2. 实验原理
- `loss(pixel, reference, material, ...)` 内部先调用 `render`，再计算 `error = color - reference`。
- 返回 `error * error`（逐通道平方误差，MSE 的像素级形式）。
- Python 端在同一帧渲染三幅图：
  - 左：reference（先渲染后降采样）；
  - 中：loss 热图；
  - 右：prediction（低分辨率材质直接渲染）。

## 3. 实验手段
- 使用 `step_04_loss.slang` 提供 `render/downsample/loss` 三个核心函数。
- 统一光照与视角，确保误差来自材质表示差异而非外部条件变化。
- `app.blit(..., tonemap=False)` 显示 loss，以减少色调映射对误差观察的干扰。

## 4. 实验条件
- 窗口宽高：`3092x1024`（三栏并排显示，含间隔）。
- 分辨率基准：低分辨率输出与 loss 均为 1/4 尺寸后放大显示。
- 损失函数：逐像素逐通道平方误差。

## 5. 实验步骤
1. 计算 reference：全分辨率渲染后降采样 2 级。
2. 计算 prediction：对降采样后的材质直接渲染。
3. 调用 `loss(...)`，以 reference 为监督生成误差图。
4. 分别将 reference / loss / prediction 输出到三栏窗口。
5. 观察高误差区域（通常出现在高频法线与高光区域）。

## 6. 实验结果
- 误差图直观展示了两条渲染路径在非线性 BRDF 下的不一致性。
- 该实验将“视觉差异”转化为可优化数值目标，为 Step 05 的自动微分训练提供了明确目标。
- 三栏布局能够快速判断：预测图与参考图越接近时，loss 图整体亮度越低。
